# ChargeWise 
### Smart EV Charging for Smarter Cities

ChargeWise is a smart EV charging platform designed to help users and city planners make better electric vehicle charging decisions. It focuses on charging station availability, charging costs, connector compatibility, and demand analysis to support more efficient and convenient EV charging.

## Problem Statement

EV users often struggle to find suitable charging stations, understand charging costs, and identify compatible charging connectors. At the same time, station operators need better insights into demand, pricing, and infrastructure utilization.

## Key Features

- **Charging Station Discovery:** Explore charging stations and their details.
- **Charging Cost Estimation:** Estimate charging expenses based on electricity consumption and station pricing.
- **Connector Compatibility:** View supported connector types, such as CCS2 and Type 2, where available.
- **Smart Analytics:** Understand charging demand, station utilization, and pricing patterns.
- **Demand-Based Insights:** Support better charging infrastructure and operational planning.

## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/dikshajain07/ChargeWise.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ChargeWise
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
